# CS 210 Portfolio – Corner Grocer Project

## Project Summary

For my CS 210 portfolio, I decided to use my Corner Grocer project. In this project, I created a program that helps a grocery store keep track of how often different items are purchased. The program lets someone search for a certain item, see how many times items were purchased, and look at a histogram that shows the results. I used C++ and Python together to get the program to work. The main goal was to make it easier for the store to understand which products customers were buying the most.

## What I Did Well

I feel like I did a good job getting the different parts of the program to work together. I was able to create a menu that lets the user choose what they want to do and see the information they need. I also tried to keep everything organized so the program would be easy to understand. Seeing the program finally work after spending time figuring everything out was probably my favorite part.

## What I Could Improve

There are definitely some things I could improve if I went back and worked on this project again. One thing would be adding better error checking, especially when someone enters something that the program is not expecting. I would also like to clean up some of my code and make it a little easier to follow. I think doing this would help the program run more smoothly and make it easier to update later.

## Challenges I Faced

One of the biggest challenges for me was figuring out how to get C++ and Python to work together. I also had trouble with some of the files and making sure everything was saved in the right place. There were times when I thought I had everything correct, but the program still would not work. I had to go back, look through my code, and figure out what I missed. I used zyBooks, my course resources, and examples to help me understand what I was doing. This project taught me to be patient and not give up just because something does not work the first time.

## Skills I Can Use in the Future

I learned quite a bit from working on this project, especially when it comes to writing C++ code, using Python, and working with files. I also got more practice finding errors and fixing problems. Since I am working toward a degree in computer science with a concentration in cybersecurity, I know these skills will help me in future classes and eventually in my career. Understanding how programs work and being able to troubleshoot problems are important skills to have.

## Making My Code Easy to Understand

I tried to keep my code organized by using comments, functions, and names that explain what different parts of the program do. I wanted someone else to be able to look at my code and understand it without having to figure everything out from scratch. I also learned that keeping things organized makes it easier to go back and make changes. This project helped me see how important it is to write code that not only works but is also easy to read and maintain.

## Final Thoughts

Overall, this project was challenging at times, but I learned a lot from it. I am still getting comfortable with programming, and I know there are things I need to keep practicing. Every project helps me understand a little more, and I feel like I am improving as I go. I am looking forward to using what I learned in future classes and continuing to build my programming skills.
